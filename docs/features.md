# Features

- Flat cockpit layout with action cards.
- Embedded terminal through xterm.js and `QWebChannel`.
- Tool approval gate for risky agent actions.
- Fleet supervisory cockpit with an approval inbox.
- Temporal graph scrubber for as-of replay of the graph.
- Ask-data, metrics and federated search panels.
- Voice dictation through the governed transcription service.
- System tray daemon for long-running agent tasks.

The [concept registry](concepts.md) maps each feature to its code path.
