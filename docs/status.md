# Status

Geniusbot is a desktop entry point for Graph OS and the connected agent platform. Most networked panels use Graph OS through the shared gateway client.

The desktop backend adapter still provides limited direct Agent Utilities paths for workspace graph execution, service-dashboard configuration and aggregation, and local log-directory resolution. Graph OS remains the governed gateway and composition host; Agent Utilities owns the agent control plane; Epistemic Graph owns durable graph data and reasoning.

Sensitive-action confirmation is presented in Geniusbot. Graph OS remains responsible for the platform policy boundary on governed service requests.
