# Start

## Requirements

- Python 3.12 through 3.14
- [uv](https://github.com/astral-sh/uv)
- A reachable `agent-utilities` backend

## Install and run

```bash
git clone https://github.com/Knuckles-Team/geniusbot.git
cd geniusbot
uv sync --all-extras
uv run geniusbot
```

The cockpit window opens on the Dashboard category.
