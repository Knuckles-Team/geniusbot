# Start

## Requirements

- Python 3.12 through 3.14
- [uv](https://github.com/astral-sh/uv)
- A reachable `meristem` backend

## Install and run

```bash
git clone https://github.com/Knuckles-Team/axil.git
cd axil
uv sync --all-extras
uv run axil
```

The cockpit window opens on the Dashboard category.
